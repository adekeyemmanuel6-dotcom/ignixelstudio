# Case Study SEO Template (use for each portfolio project)

**Rules:** only real, verified facts; client permission for names/screenshots; publish a result only if the client confirms it (a metric already present in the CMS, e.g. a revenue figure, must have written client approval before being shown). If a client is confidential, anonymise honestly (e.g. "a telehealth practice") and say so.

| Element | Guidance |
|---|---|
| **Title (≤ 60 chars)** | `<Industry> <platform> website: <outcome or project name>`. e.g. "Direct Primary Care Webflow Website: Richardson DPC" |
| **Meta description (≤ 155)** | Who the client is, what was built, the headline result if verified |
| **H1** | Project name + what was delivered |
| **Intro (2–3 lines)** | Client, industry, platform, one-line outcome |
| **Background & challenge** | The client's situation in their words; what was not working |
| **Objectives** | 3–4 measurable or observable goals |
| **Strategy** | How UX/structure decisions answered the objectives |
| **Design process** | Key design decisions with 2–3 images |
| **Development** | Platform choice and why; integrations; CMS structure |
| **Technologies** | Stated plainly (already a structured field) |
| **Features delivered** | Bulleted, specific |
| **Results** | Verified metrics only, with date range; otherwise qualitative outcomes the client confirms |
| **Client quote** | Real testimonial; link name/company only with permission |
| **Screenshots** | Desktop + mobile, descriptive `alt` ("Richardson DPC homepage on desktop") |
| **Link** | Live site if permitted; `rel` is normal follow for a real client site |
| **Internal links** | Platform page, industry page, 1–2 related projects, contact CTA |
| **Schema** | `CreativeWork` (already automatic) + breadcrumbs |

**Fixes needed on existing case studies (verified):** one title contains a typo ("Healtcare Webflow Website Development" → "Healthcare…"), several SEO titles exceed 60 characters (86–104), and only one project has any results recorded. Edit these in Admin → Projects (SEO title / results).
